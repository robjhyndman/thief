# Package index

## Main function

Produce forecasts using the THieF method

- [`thief()`](http://robjhyndman.github.io/thief/reference/thief.md) :
  Temporal hierarchical forecasting

## Helper functions

- [`tsaggregates()`](http://robjhyndman.github.io/thief/reference/tsaggregates.md)
  : Non-overlapping temporal aggregation of a time series
- [`reconcilethief()`](http://robjhyndman.github.io/thief/reference/reconcilethief.md)
  : Reconcile temporal hierarchical forecasts

## Plotting functions

- [`plot(`*`<tsaggregates>`*`)`](http://robjhyndman.github.io/thief/reference/plot.tsaggregates.md)
  [`autoplot(`*`<tsaggregates>`*`)`](http://robjhyndman.github.io/thief/reference/plot.tsaggregates.md)
  : Plot time series aggregates
